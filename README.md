# STM32 AS5600-Based Motor Position Control

An embedded motor position control system developed using an
STM32F767 Nucleo board, an AS5600 magnetic angle sensor, and a
DC motor with an H-bridge driver.

The project implements a closed-loop PI position controller
and was tested on physical hardware.

## Features

- Real-time angular position feedback over I2C
- PI-based closed-loop position control
- Bidirectional DC motor control using PWM
- Multi-turn position tracking
- Configurable target angle, rotation count, and movement speed
- Runtime parameter adjustment through STM32CubeIDE Live Expressions
- Debug variables for monitoring controller behavior

## Hardware

- STM32F767 Nucleo
- AS5600 magnetic angle sensor
- KGA25 DC geared motor
- BTS7960 H-bridge motor driver

## Software and Tools

- C
- STM32CubeIDE
- STM32 HAL
- MATLAB/Simulink

## System Overview

The AS5600 sensor measures the motor's angular position and
communicates with the STM32 over I2C.

The controller compares the measured position with the target
position and calculates a control output using a PI algorithm.

Two PWM channels generated by the STM32 control the motor
driver's direction and drive level.

The software also tracks full rotations, allowing movement
commands to specify a target angle, rotation count, and
movement speed.

## Testing

The system was tested on physical hardware.

Target angle, movement speed, and rotation count were adjusted
through STM32CubeIDE Live Expressions. The motor responded to
the commands and moved to the requested positions.

MATLAB/Simulink was also used to model the motor and analyze
the control system response.
